About

Chillspace Pin Publisher is a private tool used by Chillspace, an independent creator of printable kids' worksheets, to publish Pins about its own products to its own Pinterest account.

The App uses the Pinterest API to:

  • create Pins (image, title, description and a link to the creator's own product page) on the creator's own boards;
  • list and create the creator's own boards;
  • read analytics for the creator's own Pins to decide which designs to publish next.

The App is not offered to the public and only accesses the Pinterest account that authorizes it. Products: chillscape8.gumroad.com.
